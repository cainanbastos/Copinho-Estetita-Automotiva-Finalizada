# Copinho — Atelier Edition V5

## Como executar

1. Instale Node.js 22.13+
2. Abra esta pasta no VS Code.
3. No terminal, execute `npm install` e `npm run dev`.
4. Abra o endereço localhost exibido pelo Vite.

## Alterações desta versão

- Hero premium sofisticado com fotografia real da Copinho e tratamento editorial.
- Hierarquia visual e cartões de serviços refinados, preservando os cinco serviços, preços, descrições e links.
- Galeria sem filtros, nomes ou foto de interior, conforme solicitado na V4.
- Uma foto principal em destaque e outras sete em grade editorial.
- Animações de entrada e microinterações elegantes, respeitando preferências de movimento reduzido.
- Melhorias de contraste, legibilidade e organização em telas pequenas.

**Importante:** Todos os textos comerciais, horários, contatos, preços e funcionalidades foram preservados. As fotos são imagens reais do projeto. Não foi gerada uma falsa imagem de resultado.

## Validação sugerida

Execute `npm run dev` e confira desktop/mobile. Depois, `npm run build` e `npm run lint`. Caso a instalação falhe por acesso a registros privados, revise `.npmrc` e as dependências do projeto original.
